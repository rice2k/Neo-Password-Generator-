# Neo Password Generator v2.0.0

Version 2 adds secure passphrase generation alongside the existing cryptographic random-password generator.

## Highlights

- Random password and passphrase modes
- `crypto.getRandomValues()` based randomness
- Passphrase presets and 3–8 word phrases
- Configurable separators, capitalization, number and symbol suffixes
- Password batches up to 20 results
- Strength and entropy estimates
- Responsive Neo interface and dark/light themes
- Repository screenshot and expanded documentation

See `CHANGELOG.md` for the complete version history.
